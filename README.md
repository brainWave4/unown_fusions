# Unown Fusions
## About
This is the sprite fusions between Unown and the rest of the Pokemon. These are custom content for Pokemon Infinite Fusion.

With Unown as the head half, it abstracts the body half.
## Usage
To use the sprites for Pokemon Infinite Fusion, move `CustomBattlers` to `Graphics` in its root folder and let it merge.

# Unown Fusions
## About
This is the sprite fusions between Unown and the rest of the Pokemon. These are custom content for Pokemon Infinite Fusion.

With Unown as the head half, it abstracts the body half.
### Shiny
As of V7, how shinies work is by hue shifting depending on which combination of side of the fusion is shiny. However, as Unown is always in greyscale, its shiny form looks no different from had it not been shiny. This affects all battlers that are greyscale in color, including the Unown-head fusions here.

To rectify this, seperate sprites are included to account for the resultant shiny color. For example, shiny Unown is usually colorized to ink blue, so this applies to fusions with Shiny Unown-heads.
## Usage
To use the sprites for Pokemon Infinite Fusion, move `CustomBattlers` to `Graphics` in its root folder and let it merge.
